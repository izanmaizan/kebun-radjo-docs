# Kebun Radjo

Aplikasi Android luring untuk petani kopi Arabika anggota koperasi: memetakan kebun, mendata pohon, menjadwalkan perawatan, dan mencatat panen.

## Kegunaan

- Memetakan batas kebun dan mendata pohon.
- Menjadwalkan dan mencatat perawatan.
- Mencatat hasil panen per blok.
- Bertukar data lewat berkas tanpa server.

## Tech stack

| Lapis | Teknologi |
|---|---|
| Mobile | Expo React Native |
| Peta | MapLibre |
| Penyimpanan | Lokal di perangkat, tanpa akun dan tanpa server |
| Pertukaran data | Berkas .ksr |

## Alur singkat

1. Petani memetakan kebun dan menandai pohon.
2. Jadwal perawatan dibuat dan dicatat pelaksanaannya.
3. Panen dicatat per blok.
4. Data diekspor sebagai berkas untuk digabung di tempat lain.
